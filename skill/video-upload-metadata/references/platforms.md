# Platform limits and fields

Limits change; these were current as of late 2026. If the user reports a different limit, trust the user and note it.

## YouTube (long-form)

| Field | Limit / rule |
|---|---|
| Title | 100 chars max; ~60–70 visible in search and suggested. No `<` or `>` |
| Description | 5,000 chars max; ~150 chars visible before "more" |
| Tags | 500 chars total (a tag with spaces counts its quotes); tags matter little for ranking — mainly misspellings and variants |
| Hashtags | First 3 in the description show above the title. More than 60 hashtags → all are ignored |
| Chapters | First timestamp must be `00:00`; at least 3 chapters; each at least 10 s long; format `MM:SS Label` one per line |
| Thumbnail | 1280×720 (16:9), JPG/PNG, under 2 MB |
| Category | e.g. Music, Education, Film & Animation, Entertainment, People & Blogs, Howto & Style, Gaming |
| Audience | "Made for kids" yes/no (COPPA). Yes disables comments, notifications bell, personalised ads, mini-player |
| Altered or synthetic content | Disclose realistic AI-made or altered people, voices, places or events. Not needed for clearly unrealistic/animated content, beauty filters, or AI used only for scripts/captions |
| Other | Language, caption language, license (Standard / Creative Commons), playlist, paid promotion flag |

## YouTube Shorts

- Vertical (9:16 or square), up to 3 minutes.
- Title is the main visible text: keep under ~60 chars, hook first.
- `#Shorts` is optional (format is auto-detected) but harmless.
- Can link one related long-form video.

## TikTok

| Field | Limit / rule |
|---|---|
| Caption | 4,000 chars including hashtags; only first ~1–2 lines show without tapping |
| Hashtags | No hard cap besides caption length; 3–5 relevant tags works best |
| Cover | Choose a frame + optional text overlay |
| AI-generated content | Toggle in "More options"; required for realistic AI content (TikTok may auto-label C2PA-tagged media) |
| Audience | Users must be 13+; no "kids" setting — write for families/parents |
| Other | Location, mentions (@), allow comments/duet/stitch, "Disclose post content" for branded content |

## Instagram Reels

| Field | Limit / rule |
|---|---|
| Caption | 2,200 chars; ~125 chars visible before "more" |
| Hashtags | Capped at 5 per post (reduced from 30 in Dec 2025); keep them specific |
| Mentions | Up to 20 @mentions |
| Alt text | Under "Advanced settings → Accessibility"; plain description of what is shown |
| Cover | Pick a frame or upload an image; profile grid crops to 3:4 |
| AI label | "Add AI label" toggle; Meta may auto-apply "AI info" for detected AI media |
| Other | Collaborators (invite), location, topics, "Share to Facebook", trial reel option |
| Audience | Users must be 13+ |

## Writing rules of thumb

- Front-load the keyword and the hook in whatever is visible before truncation.
- Hashtags: mix broad (high volume) with niche (high relevance); never use banned or unrelated trending tags.
- Emojis: fine on TikTok/Instagram in moderation; at most 1–2 in YouTube titles, none if the channel tone is formal.
- Keep CTAs single and specific ("Save this for bedtime" beats "like, comment, share, subscribe").
